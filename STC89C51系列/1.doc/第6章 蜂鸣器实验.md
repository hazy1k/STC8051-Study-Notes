# 第六章 驱动蜂鸣器

## 1. 导入

在掌握了LED的多种控制方式后，本章将引入另一种常见的输出设备——**蜂鸣器**。通过驱动蜂鸣器发出声音，我们可以实现报警、提示音、音乐播放等功能，拓展单片机的人机交互能力。

本章主要目标：

- 认识蜂鸣器的种类与工作原理；
- 掌握有源蜂鸣器的控制方法；
- 学习无源蜂鸣器发声原理及频率控制；
- 实现蜂鸣器的开关控制、变音调发声；
- 为后续学习中断、定时器、音乐播放打下基础。

通过本章学习，你将掌握单片机如何通过数字信号控制声音输出，进一步理解GPIO的多功能应用。

## 2. 硬件设计

### 2.1 蜂鸣器类型

蜂鸣器分为两种：

| 类型        | 特点                                  | 控制方式        |
| --------- | ----------------------------------- | ----------- |
| **有源蜂鸣器** | 内部自带振荡电路，只需通电即可发声，固定频率（通常2kHz~4kHz） | 高低电平控制开关    |
| **无源蜂鸣器** | 无内部振荡，需外部提供一定频率的方波信号才能发声，类似喇叭       | PWM或定时翻转I/O |

> 说明：“源”指内部是否有振荡源，**无源蜂鸣器更灵活，可播放音乐**。

### 2.2 电路连接

#### 2.2.1 有源蜂鸣器连接

- 蜂鸣器正极 → VCC（或通过三极管控制）
- 负极 → 单片机I/O口（如P2.0），中间串联一个NPN三极管（如S8050）驱动

> 为何使用三极管？
> 
> - 蜂鸣器电流较大（约30~50mA），直接接I/O可能超载；
> - 三极管起到电流放大和隔离作用。

**典型电路：**

- P2.0 → 基极（通过1kΩ电阻）
- 发射极 → GND
- 集电极 → 蜂鸣器负极
- 蜂鸣器正极 → VCC

> 此时P2.0输出高电平 → 三极管导通 → 蜂鸣器通电发声。

#### 2.2.2 无源蜂鸣器连接

电路相同，但控制信号需为**一定频率的方波**，才能产生对应音调。

> 建议：使用P2.0或P1.0等普通I/O口，避免使用P0口（需上拉）。

#### 2.2.3 续流二极管

在蜂鸣器两端并联一个**1N4148或1N4007二极管**（阴极接VCC，阳极接GND侧），用于吸收反向电动势，保护电路。

## 3. 软件设计

### 3.1 控制有源蜂鸣器（开关控制）

```c
#include <reg52.h>

sbit BUZZ = P2^0;  // 蜂鸣器控制引脚

void delay(unsigned int time) {
    unsigned int i, j;
    for (i = 0; i < time; i++)
        for (j = 0; j < 125; j++);
}

void main() {
    BUZZ = 1;        // 关闭蜂鸣器（三极管导通时低电平有效？需看电路）
    
    // 若电路为高电平驱动三极管，则：
    BUZZ = 1;        // 三极管导通 → 蜂鸣器响
    delay(1000);
    BUZZ = 0;        // 三极管截止 → 蜂鸣器停
    delay(1000);
    
    while(1);        // 停止
}
```

> **注意：** 实际逻辑取决于电路设计。常见两种接法：
> 
> - **低电平有效**：BUZZ = 0 → 三极管导通 → 响；
> - **高电平有效**：BUZZ = 1 → 三极管导通 → 响。

建议统一使用**低电平有效**设计，代码如下：

```c
#define BUZZ_ON  BUZZ = 0
#define BUZZ_OFF BUZZ = 1

void main() {
    BUZZ_OFF;
    while(1) {
        BUZZ_ON;     // 响
        delay(500);
        BUZZ_OFF;    // 停
        delay(500);
    }
}
```

### 3.2 驱动无源蜂鸣器发声（产生音调）

#### 3.2.1 基本原理

声音由振动产生。无源蜂鸣器需要外部方波驱动，频率决定音调。

常见音符频率（中音区）：

| 音符  | 频率（Hz） |
| --- | ------ |
| Do  | 262    |
| Re  | 294    |
| Mi  | 330    |
| Fa  | 349    |
| So  | 392    |
| La  | 440    |
| Si  | 494    |
| Do' | 523    |

#### 3.2.2 方波生成方法

使用延时函数翻转I/O电平，生成方波。周期 T=f1​，半周期为 2T​。

```c
void play_note(unsigned int freq) {
    unsigned int period = 1000000 / freq;  // 周期（μs）
    unsigned int half = period / 2;
    
    // 生成一段时间的方波
    unsigned int i;
    for (i = 0; i < 200; i++) {  // 控制发声时长
        BUZZ = 0;
        delay_us(half);
        BUZZ = 1;
        delay_us(half);
    }
}
```

> 但51单片机C语言无`delay_us`，需自定义微秒级延时。

#### 3.2.3 微秒级延时函数

```c
void delay_us(unsigned int us) {
    while(us--) {
        _nop_(); _nop_(); _nop_(); _nop_();
        _nop_(); _nop_(); _nop_(); _nop_();
        // 每次循环约8个机器周期
        // 11.0592MHz下，1机器周期≈1.085μs
        // 可根据实际调整空指令数量
    }
}
```

> 需包含头文件：`#include <intrins.h>` 以使用 `_nop_()`。

### 3.3 播放简单音乐（示例：两只老虎）

定义音符和时长：

```c
#include <reg52.h>
#include <intrins.h>

sbit BUZZ = P2^0;

void delay_us(unsigned int us) {
    while(us--) _nop_();  // 简化延时，实际需校准
}

void delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 125; j++);
}

void play_note(unsigned int freq, unsigned int duration) {
    unsigned int period = 1000000 / freq;
    unsigned int half = period / 2;
    unsigned int count = duration * 1000 / period;  // 总周期数
    
    while(count--) {
        BUZZ = 0;
        delay_us(half);
        BUZZ = 1;
        delay_us(half);
    }
    delay_ms(50);  // 音符间小间隔
}

void main() {
    while(1) {
        play_note(262, 500);  // Do
        play_note(294, 500);  // Re
        play_note(262, 500);  // Do
        play_note(294, 500);  // Re
        delay_ms(1000);       // 停顿
    }
}
```

> 说明：此为简化版，实际音乐需更精确时长与频率。

本章通过驱动蜂鸣器，掌握了单片机声音输出的基本方法，主要内容包括：

- **硬件连接**：学会使用三极管驱动蜂鸣器，理解续流二极管的重要性；

### 4.1 常见问题与解决

| 问题    | 原因          | 解决方法           |
| ----- | ----------- | -------------- |
| 蜂鸣器不响 | 接线错误、三极管未导通 | 检查电路，测量基极电压    |
| 声音微弱  | 驱动电流不足      | 检查三极管型号，确认饱和导通 |
| 程序跑飞  | 延时函数过长或堆栈溢出 | 优化代码，避免深层嵌套    |
| 音调不准  | 延时不准、晶振误差   | 使用定时器替代延时，提高精度 |
