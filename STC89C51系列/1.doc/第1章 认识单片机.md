# 第一章 51单片机简介

51单片机是指以Intel公司推出的MCS-51系列为核心架构的一类8位微控制器，其典型代表为8051。尽管诞生于20世纪80年代，51单片机因其结构简单、易于学习、资源丰富、生态成熟，至今仍广泛应用于教学、工业控制和嵌入式入门开发中。

---

**基本特性**

- **8位CPU**：一次可处理8位数据。
- **片内振荡器**：通常需外接晶振（如11.0592MHz或12MHz）。
- **4KB程序存储器（Flash）**：用于存放用户程序（不同型号可能有差异）。
- **128字节RAM**：用于数据暂存，支持工作寄存器组切换。
- **4个8位并行I/O端口**：P0、P1、P2、P3，共32个I/O引脚。
- **2个16位定时/计数器**：可用于定时、计数、产生延时等。
- **全双工串行通信口（UART）**：支持串口通信。
- **5个中断源**：具备两级优先级，支持中断嵌套。
- **片内时钟电路**：配合晶振使用，产生工作时序。

---

**引脚功能概述（以最常见的DIP-40封装STC89C52为例）**

| 引脚    | 名称          | 功能说明                        |
| ----- | ----------- | --------------------------- |
| 1-8   | P1.0 - P1.7 | P1口，通用I/O                   |
| 9     | RST         | 复位引脚，高电平有效（通常接复位电路）         |
| 10-17 | P3.0 - P3.7 | P3口，具有第二功能（如串行通信、外部中断等）     |
| 18-19 | XTAL2、XTAL1 | 外接晶振引脚                      |
| 20    | GND         | 接地                          |
| 21-28 | P2.0 - P2.7 | P2口，通常用于访问外部存储器时的高8位地址      |
| 29    | PSEN        | 外部程序存储器选通信号                 |
| 30    | ALE/PROG    | 地址锁存允许信号                    |
| 31    | EA/VPP      | 访问外部程序存储器使能（接高使用内部ROM）      |
| 32-39 | P0.0 - P0.7 | P0口，开漏输出，需外加上拉电阻，也用于地址/数据复用 |
| 40    | VCC         | 电源（+5V）                     |

---

**最小系统组成**

要使51单片机正常工作，必须构建最小系统，主要包括：

1. **电源电路**：VCC接+5V，GND接地。
2. **时钟电路**：在XTAL1和XTAL2之间接11.0592MHz晶振，两端各接一个30pF电容到地。
3. **复位电路**：RST引脚通过10μF电容接VCC，同时通过10kΩ电阻接地，实现上电自动复位。

---

**开发流程简介**

1. **编写程序**：使用C语言（Keil C51）或汇编语言。
2. **编译生成HEX文件**：在Keil μVision等IDE中编译。
3. **下载程序**：通过编程器或串口（配合STC烧录工具）将HEX文件烧录到单片机。
4. **运行调试**：观察硬件行为，使用示波器或调试工具排错。

---

**常用开发工具**

- **Keil μVision**：主流的51单片机集成开发环境。
- **Proteus**：电路仿真软件，可与Keil联调。
- **STC-ISP**：STC系列单片机的烧录工具。
- **USB转TTL模块**：用于串口下载程序。

---

**典型应用**

- LED控制
- 数码管显示
- 按键检测
- 电机驱动
- 温度采集（配合DS18B20）
- 串口通信（与PC或其他设备）

---

**学习建议**

1. 从点亮一个LED开始，理解GPIO操作。
2. 掌握定时器和中断机制。
3. 学习串口通信协议（UART）。
4. 实践按键、数码管、LCD等外设驱动。
5. 结合Proteus仿真，减少硬件成本。

---

**示例：点亮LED（C语言）**

```c
#include <reg52.h>

sbit LED = P1^0;  // 定义P1.0控制LED

void main() {
    LED = 0;      // LED亮（低电平点亮，共阳接法）
    while(1);     // 死循环
}
```

> 说明：假设LED正极接VCC，负极通过电阻接P1.0，则P1.0输出低电平点亮LED。
