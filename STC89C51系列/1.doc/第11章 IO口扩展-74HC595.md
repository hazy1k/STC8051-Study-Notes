# 第十一章 I/O口扩展-74HC595

## 1. 导入

随着项目复杂度增加，51单片机有限的I/O资源（尤其是P0~P3）可能无法满足需求。例如：驱动多位数码管、控制多个LED、连接矩阵键盘等，都会迅速耗尽可用引脚。

本章介绍一种常用的**I/O口扩展方案**：使用**74HC595**芯片，通过**串行输入、并行输出**的方式，仅用3个单片机I/O口即可扩展出8位（甚至更多）的并行输出端口。

本章目标：

- 理解74HC595的工作原理；
- 掌握其引脚功能与时序控制；
- 实现单片机通过74HC595控制8个LED；
- 学习串行移位与锁存机制；
- 为后续驱动点阵、多路继电器等应用打下基础。

## 2. 硬件设计

### 2.1 74HC595简介

74HC595是一款**8位串行输入、并行输出**的移位寄存器，具有三态输出和锁存功能，广泛用于I/O扩展。

#### 主要特性：

- 工作电压：2V ~ 6V（兼容5V系统）；
- 串行输入，并行输出；
- 支持多片级联；
- 带输出锁存器，防止显示闪烁；
- 高驱动能力（可直接驱动LED）。

---

### 2.2 引脚功能（16引脚DIP封装）

| 引脚      | 名称       | 功能说明                 |
| ------- | -------- | -------------------- |
| 1~7, 15 | Q0~Q7    | 8位并行输出端              |
| 8       | GND      | 接地                   |
| 9       | Q7S (QS) | 串行输出（用于级联）           |
| 10      | MR       | 主复位（低电平有效，通常接VCC）    |
| 11      | SH_CP    | 移位寄存器时钟输入（上升沿移位）     |
| 12      | ST_CP    | 存储寄存器时钟输入（上升沿锁存）     |
| 13      | OE       | 输出使能（低电平有效，接GND启用输出） |
| 14      | DS       | 串行数据输入               |
| 16      | VCC      | 电源+5V                |

---

### 2.3 电路连接

将74HC595与51单片机连接：

| 74HC595引脚        | 连接说明               |
| ---------------- | ------------------ |
| DS (14)          | → P1.0（定义为DATA引脚）  |
| SH_CP (11)       | → P1.1（定义为CLK引脚）   |
| ST_CP (12)       | → P1.2（定义为LATCH引脚） |
| OE (13)          | → GND（启用输出）        |
| MR (10)          | → VCC（禁止复位）        |
| Q0~~Q7 (1~~7,15) | → 8个LED负极（共阳极接法）   |
| VCC, GND         | 接电源                |

> 每个LED串联220Ω限流电阻，正极接VCC。

## 3. 软件设计

### 3.1 工作原理

74HC595工作分为两个阶段：

1. **串行移位**：通过`DS`引脚逐位输入数据，在每个`SH_CP`上升沿将数据移入内部移位寄存器；
2. **并行锁存**：当8位数据全部移入后，给`ST_CP`一个上升沿，将数据从移位寄存器复制到输出锁存器，实现并行输出。

---

### 3.2 基本操作函数

```c
#include <reg52.h>

// 定义连接引脚
sbit HC595_DATA = P1^0;  // DS
sbit HC595_CLK  = P1^1;  // SH_CP
sbit HC595_LATCH = P1^2; // ST_CP

// 微秒级延时（确保时序）
void delay_us() {
    _nop_(); _nop_(); _nop_();
}

// 发送一个字节数据到74HC595
void hc595_send(unsigned char dat) {
    unsigned char i;
    for (i = 0; i < 8; i++) {
        HC595_DATA = dat & 0x80;  // 取最高位输出
        dat <<= 1;                // 左移一位

        HC595_CLK = 0;
        delay_us();
        HC595_CLK = 1;            // 上升沿移位
        delay_us();
    }
}

// 锁存数据（更新输出）
void hc595_latch() {
    HC595_LATCH = 0;
    delay_us();
    HC595_LATCH = 1;              // 上升沿锁存
    delay_us();
}
```

### 3.3 点亮单个LED

让Q0输出低电平，其余高电平（共阳极LED亮）：

```c
void main() {
    hc595_send(0x01);   // Q0=1 → 对应LED灭；但共阳极需低电平亮？
    hc595_latch();

    // 若LED正极接VCC，负极接Q，则Q输出低电平时亮
    // 所以要让Q0=0 → 输出0xFE（11111110）
    hc595_send(0xFE);
    hc595_latch();

    while(1);
}
```

### 3.4 流水灯效果

```c
void main() {
    unsigned char i;
    unsigned char led = 0x01;  // 初始Q0亮（低电平对应位为0）

    while(1) {
        hc595_send(~led);      // 取反：因为低电平点亮
        hc595_latch();
        delay_us();

        led <<= 1;             // 左移
        if (led == 0) led = 0x01; // 循环
        delay_ms(200);
    }
}
```

> 注意：`~led` 是因为我们要输出低电平点亮LED。

### 3.5 多片74HC595级联

若需扩展16位输出，可将两片74HC595级联：

- 第一片的`Q7S`（9脚）接第二片的`DS`（14脚）；
- `CLK`和`LATCH`并联；
- 先发送第二片的数据，再发送第一片的。

```c
void hc595_send16(unsigned int dat) {
    unsigned char i;
    // 先发高8位（第二片）
    for (i = 0; i < 8; i++) {
        HC595_DATA = (dat >> 7) & 0x01;
        dat <<= 1;
        HC595_CLK = 0; delay_us();
        HC595_CLK = 1; delay_us();
    }
    // 再发低8位（第一片）
    for (i = 0; i < 8; i++) {
        HC595_DATA = (dat >> 7) & 0x01;
        dat <<= 1;
        HC595_CLK = 0; delay_us();
        HC595_CLK = 1; delay_us();
    }
    HC595_LATCH = 0; delay_us();
    HC595_LATCH = 1;
}
```

### 4.1 常见问题与解决

| 问题   | 原因           | 解决方法                     |
| ---- | ------------ | ------------------------ |
| 无输出  | OE未接地或MR悬空   | OE接GND，MR接VCC            |
| 输出错乱 | 时序错误或CLK干扰   | 检查代码时序，增加延时              |
| 闪烁   | 未锁存或LATCH未触发 | 确保每次发送后调用`hc595_latch()` |
| 级联失败 | 数据顺序错误       | 先发高位片，再发低位片              |
