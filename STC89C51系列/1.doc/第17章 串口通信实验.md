# 第十七章 串口通信（UART）

## 1. 导入

在前面章节中，我们通过LED、数码管、按键等人机交互方式获取信息，但缺乏与PC或其他设备的**数据交换能力**。本章学习51单片机的**串行通信接口（UART）**，实现单片机与计算机之间的双向通信。

串口通信（又称RS-232通信）是一种广泛应用的异步通信方式，具有接线简单、协议清晰、调试方便等优点。通过本章学习，你将掌握：

- UART的基本概念与通信格式；
- 51单片机串口寄存器的配置；
- 实现单片机向PC发送数据（发送字符串、数字）；
- 接收PC发送的指令并响应；
- 使用串口调试助手进行测试；
- 为后续实现远程控制、数据采集系统打下基础。

## 2. 硬件设计

### 2.1 串口通信原理

UART（Universal Asynchronous Receiver/Transmitter）采用**异步串行通信**，无需时钟线，通过**起始位、数据位、停止位**实现数据同步。

#### 通信格式（典型）：

```c
1位起始位（低电平）

8位数据位（LSB先发）

1位停止位（高电平）

```

> 可选奇偶校验位，本章不使用。

### 2.2 51单片机串口引脚

- **TXD**：发送数据 → P3.1（固定引脚）
- **RXD**：接收数据 → P3.0（固定引脚）

### 2.3 电平转换电路

PC的串口使用**RS-232电平**（-12V ~ +12V），而51单片机为**TTL电平**（0V/5V），必须通过**电平转换芯片**（如MAX232或CH340）连接。

#### 常见方案：

| 方案                         | 说明                             |
| -------------------------- | ------------------------------ |
| **MAX232 + DB9**           | 传统RS-232接口，需外接电容               |
| **CH340/PL2303 USB转TTL模块** | 推荐！通过USB连接PC，驱动后虚拟串口，直接TTL电平输出 |

> 本章推荐使用 **USB转TTL模块**，接线如下：

| 单片机        | USB-TTL模块 |
| ---------- | --------- |
| P3.0 (RXD) | TX        |
| P3.1 (TXD) | RX        |
| GND        | GND       |
| VCC        | VCC（可选供电） |

> 注意：**交叉连接**：单片机TXD → 模块RX；单片机RXD → 模块TX。

## 3. 软件设计

### 3.1 串口相关寄存器

| 寄存器         | 功能说明              |
| ----------- | ----------------- |
| **SBUF**    | 串口数据缓冲寄存器，发送和接收共用 |
| **SCON**    | 串口控制寄存器           |
| **TMOD**    | 定时器模式寄存器（用于设置波特率） |
| **TH1/TL1** | 波特率发生器初值（使用T1）    |

#### SCON格式：

| SM0 | SM1 | SM2 | REN | TB8 | RB8 | TI     | RI     |
| --- | --- | --- | --- | --- | --- | ------ | ------ |
| 0   | 1   | 0   | 1   | 0   | 0   | 发送中断标志 | 接收中断标志 |

> 设置 **SM1=1**，选择**方式1**（8位UART），最常用。

---

### 3.2 波特率设置

常用波特率：9600、19200、115200  
使用定时器T1（方式2，8位自动重装）产生波特率。

#### 公式（晶振11.0592MHz，SMOD=0）：

![屏幕截图 2025-10-17 142551.png](https://raw.githubusercontent.com/hazy1k/My-drawing-bed/main/2025/10/17-14-25-58-屏幕截图%202025-10-17%20142551.png)

| 波特率    | TH1（十六进制）     |
| ------ | ------------- |
| 9600   | 0xFD          |
| 19200  | 0xFA          |
| 115200 | 0xFF（需SMOD=1） |

> 本章使用 **9600bps**。

---

### 3.3 串口初始化函数

```c
#include <reg52.h>

void uart_init() {
    TMOD = 0x20;      // T1工作方式2（8位自动重装）
    TH1  = 0xFD;      // 9600bps
    TL1  = 0xFD;
    TR1  = 1;         // 启动T1
    SCON = 0x50;      // 方式1，允许接收（REN=1）
    PS   = 0;         // 串口中断优先级（可选）
    EA   = 1;         // 开总中断
    ES   = 1;         // 开串口中断
}
```

---

### 3.4 发送一个字节

```c
void uart_send_byte(unsigned char dat) {
    SBUF = dat;               // 写入SBUF启动发送
    while(TI == 0);           // 等待发送完成
    TI = 0;                   // 清发送标志
}
```

---

### 3.5 发送字符串

```c
void uart_send_string(unsigned char *str) {
    while(*str) {
        uart_send_byte(*str++);
    }
}
```

---

### 3.6 发送数字（整数）

```c
void uart_send_int(int num) {
    unsigned char buf[6], i = 0, is_neg = 0;

    if (num == 0) {
        uart_send_byte('0');
        return;
    }
    if (num < 0) {
        is_neg = 1;
        num = -num;
    }

    while (num) {
        buf[i++] = num % 10 + '0';
        num /= 10;
    }

    if (is_neg) uart_send_byte('-');
    while (i > 0) {
        uart_send_byte(buf[--i]);
    }
}
```

---

### 3.7 接收中断服务函数

```c
unsigned char rx_data = 0;

void uart_isr() interrupt 4 {
    if (RI) {
        RI = 0;                    // 清接收标志
        rx_data = SBUF;            // 读取接收到的数据

        // 回显：收到什么就发回去
        uart_send_byte(rx_data);

        // 示例：收到'1'点亮LED，收到'0'熄灭
        if (rx_data == '1') {
            P1 = 0x00;
        } else if (rx_data == '0') {
            P1 = 0xFF;
        }
    }
    if (TI) {
        TI = 0;                    // 发送中断处理（可选）
    }
}
```

---

### 3.8 主程序示例

```c
void main() {
    uart_init();
    P1 = 0xFF;  // LED初始熄灭

    uart_send_string("UART Test Start!\r\n");

    unsigned char cnt = 0;
    while(1) {
        // 每2秒发送一次计数
        delay_ms(2000);
        uart_send_string("Count: ");
        uart_send_int(cnt++);
        uart_send_string("\r\n");
    }
}
```

### 4.1 常见问题与解决

| 问题   | 原因           | 解决方法        |
| ---- | ------------ | ----------- |
| 无数据  | 接线错误（未交叉）    | 检查TXD/RXD连接 |
| 数据乱码 | 波特率不匹配       | 确认双方波特率一致   |
| 接收不到 | REN未开启或中断未使能 | 检查SCON和ES设置 |
| 下载失败 | P3.0被占用      | 下载时断开RXD线   |
