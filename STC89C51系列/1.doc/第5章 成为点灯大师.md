## 2. 硬件设计

### 2.1 电路连接

扩展LED数量至8个，连接到P1口的8个引脚：

| LED  | 阳极  | 阴极连接 | 限流电阻 |
| ---- | --- | ---- | ---- |
| LED0 | VCC | P1.0 | 220Ω |
| LED1 | VCC | P1.1 | 220Ω |
| ...  | ... | ...  | ...  |
| LED7 | VCC | P1.7 | 220Ω |

即：8个LED共阳极接VCC，阴极分别接P1.0 ~ P1.7，每个串联220Ω电阻。

> 说明：P1口内部有弱上拉电阻，但驱动LED时仍建议使用外部限流电阻。

### 2.2 最小系统要求

确保以下电路正常工作：

- **电源**：VCC = +5V，GND接地；
- **晶振**：11.0592MHz，配30pF电容；
- **复位电路**：10μF电容接VCC，10kΩ电阻接地，RST接电容与电阻之间；
- **EA引脚**：接高电平（VCC），使用内部程序存储器。

### 2.3 可选扩展：使用P0口驱动

若使用P0口连接LED，需注意：

- P0口为开漏输出，必须外接上拉电阻（10kΩ×8）或使用排阻；
- 否则无法稳定输出高电平，可能导致LED异常点亮或不亮。

## 3. 软件设计

### 3.1 流水灯（从左到右/从右到左）

#### 基本原理

让LED依次点亮，形成“流动”效果。利用循环和位移操作实现。

#### 程序实现

```c
#include <reg52.h>

#define LED_PORT P1

void delay(unsigned int time) {
    unsigned int i, j;
    for (i = 0; i < time; i++)
        for (j = 0; j < 125; j++);
}

void main() {
    unsigned char i;
    while(1) {
        // 从左到右（P1.0 → P1.7）
        for (i = 0; i < 8; i++) {
            LED_PORT = ~(0x01 << i);  // 左移并取反（共阳极）
            delay(200);
        }
    }
}
```

> 说明：
> 
> - `0x01 << i`：将1左移i位，如i=0→00000001，i=1→00000010；
> - `~( )`：取反，使对应位为0，其余为1；
> - 共阳极LED低电平点亮，故取反后实现单灯移动。

#### 从右到左流水

修改循环方向：

```c
for (i = 7; i >= 0; i--) {
    LED_PORT = ~(0x01 << i);
    delay(200);
}
```

> 注意：`i`为无符号数时，`i >= 0`恒成立，会导致死循环。应改为：

```c
for (i = 7; i != 0xFF; i--) {
    LED_PORT = ~(0x01 << i);
    delay(200);
}
```

或使用有符号变量。

### 3.2 双向流水灯（左右往返）

实现LED从左到右再从右到左循环。

```c
void main() {
    unsigned char i;
    while(1) {
        // 左到右
        for (i = 0; i < 8; i++) {
            LED_PORT = ~(0x01 << i);
            delay(200);
        }
        // 右到左（去掉重复点）
        for (i = 6; i > 0; i--) {
            LED_PORT = ~(0x01 << i);
            delay(200);
        }
    }
}
```

### 3.3 跑马灯（连续移动）

实现多个LED连续移动，类似“光带”效果。

```c
void main() {
    unsigned char pattern = 0x01;  // 初始状态：最低位亮
    while(1) {
        LED_PORT = ~pattern;
        delay(200);
        pattern = (pattern << 1) | (pattern >> 7);  // 左移循环
    }
}
```

> 说明：`| (pattern >> 7)` 实现循环左移，当最高位移出后回到最低位。

若只希望“前进”而不循环，可使用：

```c
pattern <<= 1;
if (pattern == 0) pattern = 0x01;
```

### 3.4 闪烁组合模式

定义多种灯光模式，通过数组控制。

```c
unsigned char code patterns[] = {
    0x00,  // 全亮
    0xFF,  // 全灭
    0x0F,  // 左4亮右4灭
    0xF0,  // 左4灭右4亮
    0x55,  // 交替亮（01010101）
    0xAA   // 交替亮（10101010）
};

void main() {
    unsigned char i;
    while(1) {
        for (i = 0; i < 6; i++) {
            LED_PORT = ~patterns[i];  // 共阳极取反
            delay(500);
        }
    }
}
```

> `code`关键字表示数据存入程序存储器（Flash），节省RAM。

### 3.5 模拟呼吸灯（PWM思想引入）

51单片机无硬件PWM，但可通过软件模拟实现亮度调节。

#### 原理

利用人眼视觉惰性，快速开关LED，改变占空比实现“亮度变化”。

```c
void breathe_led() {
    unsigned char i, j;
    for (i = 0; i < 255; i += 5) {
        for (j = 0; j < 255; j++) {
            if (j < i) {
                LED_PORT = 0xFE;  // P1.0输出低电平（亮）
            } else {
                LED_PORT = 0xFF;  // 输出高电平（灭）
            }
        }
        // 延时一小段时间
        delay(10);
    }
}
```

> 说明：此为单LED模拟，i控制占空比，循环越快，亮度越平滑。

完整呼吸效果需再反向降低亮度。

### 3.6 多模式切换控制（预留接口）

为后续引入按键控制做准备，可定义模式切换变量：

```c
unsigned char mode = 0;  // 模式编号

void loop() {
    switch(mode) {
        case 0: flow_left_to_right(); break;
        case 1: flow_right_to_left(); break;
        case 2: blink_pattern(); break;
        default: mode = 0; break;
    }
}
```

> 后续可通过按键中断修改`mode`值，实现用户交互。

### 4.1 常见问题与解决

| 问题      | 原因                | 解决方法                  |
| ------- | ----------------- | --------------------- |
| 所有LED微亮 | 程序未运行，端口电平不确定     | 检查复位电路、晶振、电源          |
| 流水方向错误  | 位移方向或取反逻辑错误       | 检查`<<`与`>>`方向，确认共阳极逻辑 |
| 延时不准确   | 晶振频率不匹配           | 修改延时参数或使用定时器          |
| 程序跑飞    | 未加`while(1)`或堆栈溢出 | 确保主循环存在，避免递归过深        |
