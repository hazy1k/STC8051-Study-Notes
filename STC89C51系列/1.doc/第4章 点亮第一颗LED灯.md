## 2. 硬件设计

### 2.1 LED工作原理

LED（发光二极管）是一种半导体器件，具有单向导通性和发光特性。当正向电压超过其导通电压（通常为1.8V~2.2V，红色LED约1.8V）时，电流流过并发光。

在51单片机系统中，常用两种接法：

- **共阳极接法**：LED正极接VCC，负极接单片机I/O口。此时I/O输出低电平（0）时LED点亮，输出高电平（1）时熄灭。
- **共阴极接法**：LED负极接地，正极接I/O口。此时I/O输出高电平（1）时LED点亮，输出低电平（0）时熄灭。

> 本章采用**共阳极接法**，这是教学中最常见的设计方式。

### 2.2 电路连接图

假设使用STC89C52单片机，两颗LED连接如下：

| LED  | 阳极  | 阴极连接 | 限流电阻 |
| ---- | --- | ---- | ---- |
| LED1 | VCC | P1.0 | 220Ω |
| LED2 | VCC | P1.1 | 220Ω |

> 电阻作用：限制电流，防止LED或单片机引脚过流损坏。典型工作电流为5~10mA。

### 2.3 最小系统完整性

确保以下最小系统电路已正确搭建：

- **电源**：VCC = +5V，GND接地；
- **晶振电路**：XTAL1与XTAL2之间接11.0592MHz晶振，两端各接30pF电容到地；
- **复位电路**：RST引脚接10μF电容到VCC，同时接10kΩ电阻到GND，实现上电复位。

## 3. 软件设计

### 3.1 头文件包含与引脚定义

所有51单片机C语言程序都需包含标准寄存器定义头文件：

```c
#include <reg52.h>
```

该头文件定义了P0、P1、P2、P3等I/O端口以及特殊功能寄存器（SFR）。

使用`sbit`关键字定义LED控制引脚：

```c
sbit LED1 = P1^0; // 定义LED1连接在P1.0

sbit LED2 = P1^1; // 定义LED2连接在P1.1
```

> 注意：`P1^0`表示P1口的第0位，不可写成`P1.0`。

### 3.2 同时点亮两个LED

最简单的功能是让两个LED同时常亮：

```c
void main() {

LED1 = 0; // P1.0输出低电平，LED1亮

LED2 = 0; // P1.1输出低电平，LED2亮

while(1); // 死循环，保持运行

}
```

程序分析：

- `main`函数执行后，立即设置两个引脚为低电平；
- `while(1);`使程序无限循环，防止单片机复位或跑飞；
- 两个LED持续点亮。

---

### 3.3 交替闪烁两个LED

实现两个LED交替闪烁，需要引入延时函数。

#### 3.3.1 软件延时函数

```c
void delay(unsigned int time) {
    unsigned int i, j;
    for (i = 0; i < time; i++) {
        for (j = 0; j < 125; j++) {
            ; // 空操作，消耗时间
        }
    }
}
```

> 延时时间估算：在11.0592MHz晶振下，内层循环约8~10us，外层循环`time`次，总延时约为 `time × 1.25ms`。可通过示波器或逻辑分析仪校准。

#### 3.3.2 主程序逻辑

```c
void main() {
    while(1) {
        LED1 = 0;        // LED1亮
        LED2 = 1;        // LED2灭
        delay(800);      // 延时约1秒

        LED1 = 1;        // LED1灭
        LED2 = 0;        // LED2亮
        delay(800);      // 延时约1秒
    }
}
```

> 实际延时时间与晶振频率、编译器优化等级有关，可根据现象调整`delay`参数。

---

### 3.4 使用端口寄存器批量控制

除了位操作，还可以直接对P1端口赋值，实现更灵活的控制。

#### 3.4.1 端口寄存器说明

P1是一个8位特殊功能寄存器，地址为0x90，每一位对应一个引脚（P1.0 ~ P1.7）。

例如：

- `P1 = 0xFE;` → 二进制 `11111110` → P1.0=0，其余为1 → 仅LED1亮
- `P1 = 0xFD;` → 二进制 `11111101` → P1.1=0，其余为1 → 仅LED2亮

#### 3.4.2 程序示例

```c
#include <reg52.h>

void delay(unsigned int time) {
    unsigned int i, j;
    for (i = 0; i < time; i++) {
        for (j = 0; j < 125; j++);
    }
}

void main() {
    while(1) {
        P1 = 0xFE;   // LED1亮，LED2灭
        delay(800);
        P1 = 0xFD;   // LED1灭，LED2亮
        delay(800);
    }
}
```

> 优点：代码简洁，适合控制多个LED；缺点：可能影响其他P1引脚状态，需注意端口复用。

### 4.1 常见问题与解决

| 问题         | 可能原因            | 解决方法                      |
| ---------- | --------------- | ------------------------- |
| LED不亮      | 接线错误、电阻过大、程序未下载 | 检查电路连接，确认程序已成功烧录          |
| 两个LED同时亮/灭 | 逻辑错误            | 检查赋值是否正确，如是否误将两个引脚都置0或1   |
| 延时不准确      | 晶振频率不符、编译优化     | 使用定时器替代软件延时，或校准延时函数       |
| 单片机不工作     | 电源、复位、晶振异常      | 用万用表检测VCC和GND，确认复位电平和晶振起振 |
