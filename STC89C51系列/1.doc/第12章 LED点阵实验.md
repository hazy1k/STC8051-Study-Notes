# 第十二章 实现LED点阵

## 1. 导入

在掌握了独立LED、数码管、74HC595等显示技术后，本章将引入更复杂的显示设备——**LED点阵屏**。LED点阵由多个LED按行和列排列组成，能够显示图形、文字和动态效果，广泛应用于广告牌、信息提示屏等场景。

本章以常见的**8×8 LED点阵**为例，通过单片机控制实现字符显示、移动效果和简单动画。学习目标包括：

- 理解LED点阵的结构与工作原理；
- 掌握共阴/共阳型点阵的驱动方式；
- 使用74HC595扩展I/O驱动列线；
- 实现点阵的静态与动态扫描；
- 显示字符“H”并实现左右移动；
- 为后续实现汉字显示、点阵广告屏打下基础。

## 2. 硬件设计

### 2.1 LED点阵结构

8×8 LED点阵内部由64个LED组成，排列为8行×8列。每个LED的阳极和阴极分别连接到行线和列线。

#### 引脚识别（以典型共阴型为例）：

- 16脚中，8根为行线（R1~~R8），8根为列线（C1~~C8）；
- 使用万用表二极管档可测试导通关系，确定行与列。

> 常见封装引脚排列不规则，需查阅数据手册或实测。

### 2.2 点阵类型

| 类型      | 行线           | 列线             | 控制逻辑           |
| ------- | ------------ | -------------- | -------------- |
| **共阴极** | 阴极连行 → 行接GND | 阳极连列 → 列接高电平点亮 | 行低 + 列高 → LED亮 |
| **共阳极** | 阳极连行 → 行接VCC | 阴极连列 → 列接低电平点亮 | 行高 + 列低 → LED亮 |

> 本章以**共阴极8×8点阵**为例。

---

### 2.3 电路连接

由于8×8点阵需要8行+8列=16个控制线，而51单片机I/O有限，采用以下方案：

- **行线（R1~R8）**：直接接P0口（P0.0~P0.7），作为行选输出；
- **列线（C1~C8）**：通过**74HC595**串行扩展输出，锁存后驱动；
- **74HC595连接**：如第九章，由P1.0（DATA）、P1.1（CLK）、P1.2（LATCH）控制。

> 注意：
> 
> - P0口需外接10kΩ上拉电阻（因开漏）；
> - 行驱动电流较大，若亮度不足，可用三极管或ULN2003驱动。

## 3. 软件设计

### 3.1 显示原理

LED点阵采用**动态扫描**方式：

- 每次选中一行（行线输出低电平）；
- 同时在列线上输出该行应点亮的LED数据（高电平）；
- 快速循环扫描8行，利用视觉惰性形成完整图像。

---

### 3.2 字模生成

要显示一个字符，需将其转化为8×8的位图数据。例如，显示字母“H”：

```c
行0: 1 0 0 0 0 0 0 1 → 0x81
行1: 1 0 0 0 0 0 0 1 → 0x81
行2: 1 0 0 0 0 0 0 1 → 0x81
行3: 1 1 1 1 1 1 1 1 → 0xFF
行4: 1 0 0 0 0 0 0 1 → 0x81
行5: 1 0 0 0 0 0 0 1 → 0x81
行6: 1 0 0 0 0 0 0 1 → 0x81
行7: 1 0 0 0 0 0 0 1 → 0x81
```

定义字模数组：

```c
unsigned char code font_H[] = {
    0x81, 0x81, 0x81, 0xFF, 0x81, 0x81, 0x81, 0x81
};
```

### 3.3 74HC595驱动函数（复用第九章代码）

```c
#include <reg52.h>
#include <intrins.h>

sbit HC595_DATA = P1^0;
sbit HC595_CLK  = P1^1;
sbit HC595_LATCH = P1^2;

void hc595_send(unsigned char dat) {
    unsigned char i;
    for (i = 0; i < 8; i++) {
        HC595_DATA = dat & 0x80;
        dat <<= 1;
        HC595_CLK = 0; _nop_();
        HC595_CLK = 1; _nop_();
    }
}

void hc595_latch() {
    HC595_LATCH = 0; _nop_();
    HC595_LATCH = 1; _nop_();
}
```

### 3.4 点阵扫描函数

```c
// 显示一个8×8图像
void display_matrix(unsigned char *img) {
    unsigned char i;
    for (i = 0; i < 8; i++) {
        P0 = 0xFF;           // 关闭所有行（共阴，高电平不导通）
        hc595_send(0x00);    // 清空列数据
        hc595_latch();

        // 输出第i行的数据
        hc595_send(img[i]);  // 列数据（高电平点亮）
        hc595_latch();

        P0 = ~(1 << i);      // 选中第i行（输出低电平）

        delay_ms(1);         // 每行显示1ms，扫描周期8ms，刷新率约125Hz
    }
}
```

### 3.5 主程序：显示“H”并左右移动

```c
// 左移一位（模拟移动效果）
void shift_left(unsigned char *arr) {
    unsigned char i;
    for (i = 0; i < 8; i++) {
        arr[i] <<= 1;
    }
}

void main() {
    unsigned char display_buf[8];
    unsigned char i;

    while(1) {
        // 复制字模到缓冲区
        for (i = 0; i < 8; i++) {
            display_buf[i] = font_H[i];
        }

        // 显示并移动
        unsigned char step;
        for (step = 0; step < 5; step++) {
            display_matrix(display_buf);
            shift_left(display_buf);
            delay_ms(500);
        }
    }
}
```

### 4.1 常见问题与解决

| 问题    | 原因       | 解决方法            |
| ----- | -------- | --------------- |
| 全亮或全灭 | 行列逻辑接反   | 交换行/列控制或调整代码逻辑  |
| 重影    | 扫描太快或未消隐 | 增加关闭行步骤，控制延时    |
| 亮度低   | 扫描时间分配不均 | 保证每行显示时间一致      |
| 移动卡顿  | 延时过长     | 优化主循环，使用定时器中断扫描 |
